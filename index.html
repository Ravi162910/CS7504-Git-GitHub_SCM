Changing the Background Colour

The background colour of a webpage can be changed using CSS. In the body section, the property background-color is used.

For example: background-color: red; changes the background of the webpage to red.

Git Commands Used

  • git init - Initializes a new local Git repository
  • git add - Stages changes for commit
  • git commit - Saves staged changes to local history
  • git pull - Fetches and merges remote changes
  • git push - Uploads local commits to GitHub
